# MiniGame Studio — Distribución de actualizaciones

Este repositorio público se utiliza **solo para los instaladores y metadatos de actualización** de MiniGame Studio para Windows.

**El código fuente de desarrollo se mantiene en un repositorio privado independiente.**

## Publicaciones

Las versiones se publicarán desde [Releases](https://github.com/Reydan2004/MiniGameStudio-Updates/releases). Una publicación validada incluirá:

- Instalador NSIS `MiniGameStudio-x.y.z-win-x64.exe`.
- Archivo de diferencias `.exe.blockmap`.
- Metadatos de actualización `latest.yml`.

Todavía no se ha publicado ninguna versión de actualización validada. No se deben subir aquí bases de datos, perfiles, fotografías, contraseñas ni material de desarrollo privado.

Las actualizaciones se probarán en Windows antes de considerarse estables.
